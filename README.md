# Computer Vision

## About

This repository contains a simple Python program using the OpenCV library to load and display an image.

## images.py

The `images.py` script uses OpenCV to read an image from the Images folder and display it in a separate window. The program waits for the user to press a key before closing the image window.

## Images Folder

The Images folder contains sample images used for the Computer Vision assignment. It includes images of two Piano shirts.

## Technologies Used

- Python
- OpenCV
